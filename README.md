# LDC_1602
This is a repository for a 16x2 LCD display. 
В этом репозитории я сделал библиотеку для LDC поскольку сам с этим столкнулся 
# Как установить библиотеку?
тут всё зависти от того где вы хотите программировать библиотека создана на Python но скоро будет версия на С++
# Для MICROBIT
зайдите в редактор и зайдите **Проекты** а потом скопируйте файл или загрузите его если хотите загрузить то нажмите на **Открыть** и выберите **LDC_1602.py**
ну а если вы захотели скопировать то нажмите на **Создать новый файл** и вставте код из **LDC_1602.py**
